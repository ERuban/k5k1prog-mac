### What's new
- **Memory Editor** (**Memory Editor…** in the main window, ⌘E). Edit the radio's 200 channels on stock and Karina firmware, UV-K5 V1 and UV-K1 / UV-K5 V3:
  - double-click to edit, change several channels at once, undo;
  - copy channels to another radio: open an editor for each and drag them across, or Copy / Paste. Values the other firmware doesn't have are converted and listed;
  - import / export CHIRP CSV and CHIRP `.img`, import a `.bin` from Read Configuration. Channel numbers are kept;
  - power-on text on stock firmware;
  - **Write to Radio** saves a backup first, writes only the changed channels, reads them back and checks them. Settings and calibration are never touched.
- **Firmware and radio are recognised** from the radio's answer. Karina's firmware is the same on the UV-K5 V1 and the UV-K1, so the editor asks once. If the selection contradicts the radio, the editor warns in red.
- **Radio status** in the main window and in the editor: which radio is on the cable, normal or firmware update mode, its firmware or bootloader version. The editor notices when another radio is plugged in.
- **Settings** (**K5K1 Prog → Settings…**, ⌘,): Auto / Light / Dark appearance, the backup folder.
- **Homebrew**: `brew install --cask eruban/tap/k5k1-prog`, `brew upgrade` brings new versions.

**Back up your calibration (Read Calibration) before you flash anything.**
