K5K1 Prog

在 Mac 上备份、恢复和刷写泉盛 UV-K5 / UV-K5 V3 / UV-K1 对讲机。

下载 macOS 版 GitHub 源代码 ♥ 捐助

或使用 Homebrew： brew install --cask eruban/tap/k5k1-prog

  • 免费开源（GPL v3）
  • 经 Apple 签名和公证
  • 无遥测
  • macOS 12 或更高版本，支持 Apple 芯片和 Intel

功能

💾

备份与恢复

读取和写入对讲机的校准数据和配置。刷机之前，先保存好出厂校准。

⚡

刷写固件

支持 UV-K5 V1 以及较新的 UV-K5 V3 / UV-K1。发送任何数据之前都会检查固件文件和 bootloader，错误的组合会被拒绝。

📋

编辑信道

200 个信道，支持原厂固件和 Karina 固件。可在对讲机之间复制信道，导入和导出 CHIRP CSV 及 .img。只写入改动过的信道，写入前先备份，写入后回读校验。

📡

识别你的对讲机

状态栏显示数据线上连接的是哪台对讲机、处于什么模式、运行什么固件。按钮随之启用或禁用，不会误操作。

🔁

与 k5prog-win 完全一致

按钮、日志和线路上的数据与 Windows 工具 k5prog-win 相同，另外加入了一些安全改进。

🔄

自动更新

从 GitHub 发布版自动更新。使用 Homebrew 时，brew upgrade 会安装新版本。

* V1 固件会让 V2 黑屏，所以本应用拒绝刷写。 用 bootloader 版本区分型号：按住 PTT 开机，然后点 Write Firmware，日志中会显示版本。

开始之前

  • 先点 Read Calibration 并保存文件：里面是你这台对讲机自己的发射功率和电池校准，别处无法获得。
  • 本应用无法区分 UV-K1 固件和 UV-K5 V3 固件：请选择对应你型号的文件。
  • 刷机风险自负。

安装

  1. 下载 .dmg，打开后把 K5K1 Prog 拖到“应用程序”文件夹。
  2. 或使用 Homebrew：brew install --cask eruban/tap/k5k1-prog
  3. 用写频线（两针 Kenwood 接头）连接对讲机，端口显示为 /dev/cu.usbserial-…

常见问题

能在 Mac 上给泉盛 UV-K5 写频吗？

可以。K5K1 Prog 原生运行在 macOS 12 或更高版本上，支持 Apple 芯片和 Intel，无需 Windows 或虚拟机。它可以备份和恢复校准与配置、刷写固件和编辑信道。

支持哪些对讲机？

使用 DP32G030 芯片的 UV-K5、UV-K5(8)、UV-K6 和 UV-5R Plus（V1），以及较新的 UV-K5 V3 和 UV-K1（PY32F071）。UV-K5 V2 / UV-K6 V2 可以备份和恢复，但会拒绝刷写固件。

写频线需要装驱动吗？

通常不需要：常见的 CH340 写频线在新版 macOS 上无需额外软件即可使用，端口显示为 /dev/cu.usbserial-…

可以代替 CHIRP 吗？

编辑信道可以：存储编辑器能编辑原厂固件和 Karina 固件的 200 个信道，并导入导出 CHIRP 的 CSV 和 .img 文件。对讲机的菜单设置不在编辑范围内。

可以刷哪些固件？

适用于你型号的任何固件文件，.bin 或 .packed.bin 均可：泉盛原厂、Karina、F4HWN 等。发送前，应用会先检查文件是否与对讲机的 bootloader 匹配。

免费吗？安全吗？

免费开源，采用 GPL v3 许可。应用经 Apple 签名和公证，没有遥测，只会连接 GitHub 检查更新。
